# 巷里小馆在线点餐

基于 Vue 3 和 Vite 的响应式点餐演示，包含 3 家模拟门店、27 道菜、分类与搜索、口味选择、按门店隔离的购物篮、首单优惠、配送信息、模拟下单和订单记录。菜品图片随项目本地提供。

网站同时支持可安装的 PWA，具备桌面图标和首次联网后的离线缓存。安装需要先将生产构建发布到 HTTPS 网站；平台无关的静态站点文件见 `dist/`。

## 启动

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可使用。生产构建使用 `npm run build`。

## 演示范围

订单与购物篮保存在浏览器 `localStorage`。下单流程仅用于交互演示，不连接后端，不会产生真实支付。

## 浏览器流程检查

开发服务启动在 `127.0.0.1:4173` 时，可执行 `node scripts/verify-flow.mjs`；截图保存至 `artifacts/`。

生产预览启动在 `127.0.0.1:4174` 时，可执行 `node scripts/verify-pwa.mjs`，验证安装清单和离线打开。
